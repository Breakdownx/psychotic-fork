# Antigravity Unlocker для Linux

Бета-порт находит установки Antigravity Desktop, IDE и CLI. На вкладке **«Обзор»** виден результат проверки каждого клиента. Автопатч использует пользовательскую службу systemd.

## Запуск из исходников

В релизе форка `v2.35.1` опубликованы пакеты для macOS. На Linux с установленным Rust выполните из корня репозитория

```sh
cargo run --locked --release --bin ag_unlocker -- --status
```

Для окна запустите ту же команду без `-- --status`. Для текстового интерфейса замените `--status` на `--tui`.

## Запуск из готового Linux-комплекта

1. Распакуйте архив `AG_<версия>_linux.tar.gz` целиком и откройте распакованную папку. В ней рядом должны лежать `ag_unlocker` и `launch.sh`.
2. Запустите `bash launch.sh` от своего пользователя. На общей папке виртуальной машины или диске с ограничением на исполнение скрипт попробует запустить копию бинарника из домашнего каталога.
3. В графическом сеансе откроется окно. При подключении по SSH без графического сеанса запуск из интерактивного терминала откроет текстовый интерфейс. Для разового отчёта используйте `./ag_unlocker --status`.

Комплект собирается под x86-64 с целевой версией glibc 2.17. Состав комплекта и требования к его сборке заданы в `build_rust.py`.

Чтобы запускать анлокер из меню приложений, выполните `bash install.sh` из распакованной папки. Скрипт копирует бинарник, скрипт запуска и доступную иконку в `~/.local/share/ag-unlocker/`, а ярлык — в `~/.local/share/applications/ag-unlocker.desktop`. Если задана непустая переменная `XDG_DATA_HOME`, оба пути отсчитываются от неё.

## Поиск установки и откат

Если клиент отсутствует в **«Обзоре»**, откройте **«Установки»**, нажмите значок папки **«Указать путь вручную»** и введите путь к каталогу установки. Примеры путей — `/opt/antigravity`, `~/.local/share/antigravity` и каталог с `agy` для CLI. Каталоги Snap доступны только для чтения и исключены из автоматического поиска.

Перед откатом сохраните работу в клиентах и скопируйте нужные записи из **«Журнала»**. Действие **«Установки» → «Полная деактивация»** закрывает клиенты, снимает патчи, удаляет службу и её данные. Копию для меню, созданную `install.sh`, и её ярлык можно отдельно удалить по путям выше.
