# Antigravity Unlocker — Linux (бета порта)

Анлокер находит установленные Desktop, IDE и CLI, показывает состояние патча и может восстанавливать его после обновления. Фоновую проверку выполняет пользовательская служба автопатча.

## Запуск — максимально просто

1. Распакуйте архив куда угодно (на общую папку VM или диск Windows — тоже
   можно: если оттуда нельзя запускать программы, анлокер сам скопирует себя в
   домашнюю папку).
2. Двойной клик по **`launch.sh`** → **«Запустить как программу»**, или в
   терминале: `bash launch.sh`. **`sudo` не нужен** — под sudo анлокер не
   запустится и скажет почему.
3. На вкладке **«Обзор»** показаны найденные установки и состояние каждой из них.
4. Управление установками находится на вкладке **«Установки»**, записи локальных
   операций — на вкладке **«Журнал»**.

Хотите запускать из меню приложений — один раз `bash install.sh`.

Без графического сеанса (сервер по SSH) анлокер сам откроется прямо в
терминале. Из каталога исходников можно запустить текстовый интерфейс командой `cargo run --locked --release -- --tui`.

## Как отключить

В разделе «Установки» действие «Полная деактивация» отключает автопатч и восстанавливает установки.

## Если установка не нашлась автоматически

На вкладке «Установки» карандаш **✏** в строке нужной установки — указать путь вручную. Типичные
места: `/opt/antigravity`, `~/.local/share/antigravity`, `~/.local/bin` (CLI).
Snap-версия не патчится (read-only), используйте не-snap установку.

## Чего на Linux пока нет

Правила NRPT и локальная служба DNS доступны в Windows.

## Файлы

| Файл | Что это |
|---|---|
| `ag_unlocker` | патчер, окно и терминальный режим (ELF x86-64, glibc 2.17+) |
| `launch.sh` | обёртка: проверяет права на запуск; без графического сеанса — терминальный режим |
| `Antigravity-Unlocker.desktop` | ярлык |
| `install.sh` | добавляет ярлык в меню приложений |
