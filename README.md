# Запуск Antigravity Unlocker 2.35.1 на Mac

Локальный комплект предназначен для Mac с Apple Silicon (серия M). Рекомендуется macOS 13 или новее.

## Из Finder

1. Откройте папку `release/AG_2.35.1_macos`. Если у вас только архив `AG_2.35.1_macos.tar.gz`, дважды нажмите на него и откройте распакованную папку.
2. Дважды нажмите `Запустить.command`. Рядом с ним должен находиться файл `ag_unlocker`.
3. Когда откроется окно Antigravity Unlocker, на вкладке **«Обзор»** нажмите **«Проверить»**, чтобы увидеть состояние установленных клиентов.

## Из Терминала

Если Терминал открыт в папке с этим README, перейдите в папку комплекта командой ниже.

```sh
cd release/AG_2.35.1_macos
```

Из папки комплекта выполните команду нужного режима.

| Режим | Команда |
|---|---|
| Графическое окно | `./Запустить.command` |
| Текстовый интерфейс | `./Запустить.command --tui` |
