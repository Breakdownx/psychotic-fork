# Как запустить Antigravity Unlocker на Mac

Комплект для Mac с процессором Apple Silicon (серия M). Рекомендуемая версия системы — macOS 13 или новее.

## Запуск из Finder

1. Если комплект ещё в архиве `.tar.gz`, дважды нажмите на архив, чтобы распаковать его.
2. Откройте распакованную папку. Оставьте `Запустить.command` и `ag_unlocker` рядом.
3. Дважды нажмите **Запустить.command**. Откроются Терминал и окно Antigravity Unlocker. На вкладке **«Обзор»** нажмите **«Проверить»**, чтобы увидеть состояние установленных клиентов.

## Запуск из Терминала

Введите `cd` и пробел, перетащите распакованную папку из Finder в окно Терминала и нажмите Return. Затем выполните команду для нужного режима.

| Режим | Команда |
|---|---|
| Обычное окно | `./Запустить.command` |
| Текстовый интерфейс в Терминале | `./Запустить.command --tui` |

Если графическое окно не открывается, запуск из Терминала покажет сообщение об ошибке. Если Терминал пишет `No such file or directory`, проверьте командой `ls`, что в текущей папке видны оба файла.

## Разрешение «Управление приложениями» (обязательно)

Antigravity установлен в `/Applications`, а macOS (начиная с Ventura) защищает приложения в этой папке: без специального права анлокер **не может изменить файлы Antigravity**, то есть патч не накладывается и деактивация не проходит.

**Признаки, что не хватает именно этого права:**

- в разделе **«Установки»** у «Antigravity · настольное приложение» стоит **«Патч не подтверждён»**, а переключатель «Разблокировка входа» не доходит до зелёного;
- в карточке вверху окна — **«macOS не даёт пропатчить Antigravity»**;
- при нажатии **«Полная деактивация»** появляется ошибка и патч остаётся на месте.

**Как выдать право:**

1. Откройте **Системные настройки → Конфиденциальность и безопасность → Управление приложениями**.
2. Включите в списке:
   - **Терминал** (из него запускается анлокер);
   - **`ag_proxy`** — фоновая служба анлокера, которая накладывает и снимает патч сама (именно её чаще всего и не хватает в списке);
   - при желании сам **`ag_unlocker`**.
3. Если `ag_proxy` ещё нет в списке — один раз запустите анлокер и включите автопатч (служба тогда появится), затем добавьте её и повторите действие.
4. Вернитесь в анлокер и снова нажмите **«Включить всё»** (или **«Полная деактивация»** для отката).

Право выдаётся один раз на компьютер. Альтернатива — запускать анлокер через `Запустить.command` **из Терминала**, которому это право уже выдано.
