# Windows — диагностика и восстановление

В релизах опубликованы пакеты только для Mac: их собирает [workflow macOS](../.github/workflows/macos.yml). Сборку для Windows выполняет отдельный [workflow Windows](../.github/workflows/windows.yml) — на каждый push и pull request, а также по кнопке **Run workflow** на вкладке Actions. Он собирает `AG_<версия>.exe` статически слинкованным с CRT, прогоняет тесты, проверяет готовый файл (ему не нужен VCRUNTIME140.dll, он отвечает на `--version` и `--status`) и прикладывает его к запуску.

Готовый EXE скачивается из раздела **Artifacts** нужного запуска: архив `AG_<версия>_windows` содержит сам файл и отчёты `ag-version.txt` и `ag-status.txt`, снятые на раннере. Релиз для Windows не публикуется.

## Получить отчёт в PowerShell

Если у вас уже есть Windows-копия анлокера, откройте PowerShell в папке с её EXE. Права администратора для отчёта не требуются. В первой строке подставьте имя своего файла. Команда дождётся завершения проверки, сохранит отчёт в `ag-status.txt` и выведет код результата.

```powershell
$exe = (Resolve-Path '.\ag_unlocker.exe').Path
$report = Join-Path $PWD 'ag-status.txt'
$check = Start-Process -FilePath $exe -ArgumentList '--status' -NoNewWindow -Wait -PassThru -RedirectStandardOutput $report
$check.ExitCode
Get-Content -LiteralPath $report -Encoding UTF8
```

| Код | Что обнаружила проверка |
|---|---|
| `0` | Во всех найденных установках проверенные бинарники имеют признаки патча. |
| `1` | Хотя бы в одной установке обнаружен исходный файл, файл с неизвестной сигнатурой, ошибка чтения или отсутствуют ожидаемые бинарники. |
| `2` | Установок Antigravity в проверенных путях не найдено. |

В начале отчёта указана версия анлокера. Ниже перечислены пути к клиентам и результаты по каждому файлу. Строка «Служба автопатча» в Windows показывает, зарегистрирована ли соответствующая задача в Планировщике. Код выхода относится к состоянию файлов. Для проверки входа в аккаунт откройте сам клиент.

## Найти журнал

Если окно открыто, нажмите **«Журнал» → «Скопировать журнал»**, чтобы сохранить до 400 последних записей сеанса. Записи фоновой задачи хранятся в профиле пользователя, под которым она работала. Следующая команда покажет последние 50 строк, если служба уже создала журнал.

```powershell
$log = Join-Path $env:LOCALAPPDATA 'AGUnlocker\watchdog.log'
if (Test-Path -LiteralPath $log) {
    Get-Content -LiteralPath $log -Tail 50 -Encoding UTF8
}
```

## Вернуться к штатной установке

1. Сохраните открытые проекты и нужные журналы. Деактивация закрывает процессы Antigravity и при успешном завершении удаляет данные службы, включая журнал.
2. Запустите имеющуюся копию анлокера от имени администратора. На вкладке **«Установки»** выберите **«Полная деактивация» → «Деактивировать»**.
3. После сообщения **«Анлокер полностью деактивирован»** откройте нужный клиент Antigravity и проверьте вход. При сообщении **«Деактивация не завершена»** скопируйте журнал текущего сеанса. В нём указано, какой шаг нужно повторить после устранения ошибки.
