# Antigravity Unlocker для Mac

Сборка для macOS 13 и новее. Универсальное приложение работает на Mac с Apple Silicon и Intel.

## Установка

1. Скачайте `Psychotic_AG_Fork.dmg` со [страницы релиза](https://github.com/Breakdownx/psychotic-fork/releases/latest) и откройте образ в Finder.
2. Перетащите **Antigravity Unlocker** на ярлык **Applications**. Затем откройте приложение из папки «Программы».
3. На вкладке **«Обзор»** нажмите **«Проверить»**, чтобы увидеть результат для каждого установленного клиента.

Также можно распаковать `AG_<версия>_macOS_universal_app-local.zip` и перенести **Antigravity Unlocker.app** в «Программы». Для запуска из папки есть отдельный архив `AG_<версия>_macos.tar.gz`. Распакуйте его целиком, оставьте `Запустить.command` рядом с `ag_unlocker` и дважды нажмите на скрипт.

## Первый запуск

Приложение в релизе 2.35.1 имеет локальную подпись ad hoc. Если macOS сообщает, что не удалось проверить разработчика, сначала убедитесь, что скачали файл из нужного релиза. После попытки запуска откройте **Системные настройки → Конфиденциальность и безопасность** и подтвердите открытие именно этого приложения. [Инструкция Apple](https://support.apple.com/ru-ru/102445)

## Когда macOS отказывает в записи

Если журнал сообщает **«macOS не даёт записать»** для файла внутри Antigravity, откройте **Системные настройки → Конфиденциальность и безопасность → Управление приложениями**. Выберите приложение, которому система отказала в записи.

| Как запущен анлокер | Какую запись искать |
|---|---|
| Приложение из «Программ» | **Antigravity Unlocker** |
| Фоновая служба, установленная из приложения | Копия **Antigravity Unlocker**. В списке могут быть две одноимённые записи |
| Отдельный бинарник или `Запустить.command` | **Терминал** или другая программа, из которой запущен бинарник |
| Фоновая служба, установленная из отдельного бинарника | **ag_watchdog**. У прежней службы могло быть имя **ag_proxy** |

Повторите действие, которое завершилось ошибкой. При включённом автопатче работающая служба повторяет попытку после отказа в записи примерно через пять минут. Её журнал по умолчанию находится в `~/.local/share/agunlocker/watchdog.log`. Если задана непустая переменная `XDG_DATA_HOME`, используйте `$XDG_DATA_HOME/agunlocker/watchdog.log`.

## Запуск из Терминала

```sh
"/Applications/Antigravity Unlocker.app/Contents/MacOS/ag_unlocker" --status
```

`--status` печатает отчёт по файлам Desktop, IDE и CLI, настройке автопатча и фоновой службе. Окна клиентов остаются открытыми. Для непатченного файла внутри `.app` проверка пытается создать рядом временный файл и при успехе сразу удаляет его.

| Код выхода | Результат |
|---|---|
| `0` | У всех найденных установок подтверждён патч |
| `1` | Хотя бы у одной установки патч не подтверждён |
| `2` | Установки не найдены |

Состояние службы смотрите в отдельной строке **«Служба автопатча»**. Чтобы открыть текстовый интерфейс, замените `--status` на `--tui`. Для просмотра версии укажите `--version`.
